# schmuhlsche skills

Claude-Code-Skills aus eigenen Projekten. Jeder Skill wächst mit jedem Projekt.

| Skill | Wofür |
|---|---|
| [schmuhlsche-skills](schmuhlsche-skills/SKILL.md) | Maker-Projekte mit 3D-Druck, build123d-CAD, Elektronik und Einkauf |

## Einbinden

Ordner nach `~/.claude/skills/` verlinken, z. B. unter Windows:

```powershell
New-Item -ItemType Junction -Path "$env:USERPROFILE\.claude\skills\schmuhlsche-skills" -Target "$PWD\schmuhlsche-skills"
```

## Pflege

Nach jedem Projekt eine Rückschau nach [schmuhlsche-skills/rueckschau.md](schmuhlsche-skills/rueckschau.md).
